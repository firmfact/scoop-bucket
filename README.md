# firmfact Scoop bucket

[Scoop](https://scoop.sh/) bucket for the [firmfact](https://firmfact.com/)
command-line interface.

```powershell
scoop bucket add firmfact https://github.com/firmfact/scoop-bucket
scoop install firmfact
```

Upgrade with `scoop update firmfact`. More ways to install:
https://firmfact.com/cli

The manifest in `bucket/` is written automatically by the release workflow of
[firmfact/cli](https://github.com/firmfact/cli); please open issues and pull
requests there.
